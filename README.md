# Heart Disease Prediction

## Overview

This project uses **Machine Learning techniques** to predict whether a person is at risk of heart disease based on various medical parameters such as age, sex, chest pain type, blood pressure, cholesterol level, heart rate, and other clinical features.

The aim of this project is to build a predictive model that can assist in the early detection of heart disease and support better healthcare decision-making.

## Features

- Data preprocessing and data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization for better understanding of patterns
- Training and testing of machine learning models
- Heart disease prediction using classification algorithms
- Model performance evaluation using accuracy, confusion matrix, and other evaluation metrics

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithms Used

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Other classification algorithms (if implemented)

## Objective

The main objective of this project is to develop a reliable machine learning model that predicts the possibility of heart disease based on patient health parameters. This can help in early diagnosis and increase awareness about heart health.

## Dataset

The project uses a publicly available heart disease dataset containing patient medical records and diagnostic attributes such as:

- Age
- Gender
- Blood Pressure
- Cholesterol Level
- Heart Rate
- Chest Pain Type
- Other clinical features

## Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Model Testing
7. Performance Evaluation
8. Heart Disease Prediction

## Evaluation Metrics

The model performance is evaluated using:

- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score

## Output

The model predicts whether the patient is:

- **At Risk of Heart Disease**
- **Not At Risk of Heart Disease**
